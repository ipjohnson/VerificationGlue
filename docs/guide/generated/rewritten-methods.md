# Generated tier 3 copies

This page shows the code the generator writes for a `[Verify]` method when tier 3 is on. After reading it you can find the copy that runs in place of your method, and see where each value in its message comes from.

## One copy per method

For each eligible method, the generator writes a file that declares the method's types again as `partial` and adds a method named `{Name}__Verified` with the same parameters. The file repeats the `using` directives of the source file, so the copied statements bind as they did in your file. The copy carries `[VerifiedCopy]` with the contract version, and `[EditorBrowsable(Never)]` keeps it out of completion lists.

The body is your body with each `Verify` and `Check` statement replaced by an `if`:

- Before the `if`, one typed local per part of the condition. A `#line hidden` directive keeps these lines out of the debugger.
- In the condition, each part is assigned to its local as it runs, `(__vg0_1 = order.Shipping)`. The condition keeps its shape, so evaluation order and short-circuiting do not change.
- On failure, the `VerifyFailure` builder reads the locals. A part on a skipped side gets `evaluated: false` from the locals that decided it.

`#line` directives map every other line to your file, so breakpoints and stack traces point at your source.
