# Generated entry types

This page shows the code the generator of `VerificationGlue.Tests.AspNetCore` writes for a class marked `[WebAppEntry]`. After reading it you can tell which method of your app a test calls, and why the test project needs no access to the app's `Program` class.

## What the generator writes

For each partial class marked `[WebAppEntry("App")]`, the generator writes `{Namespace}.{Class}.WebAppEntry.g.cs`. The file makes the class implement `IWebAppEntry`:

- `ApplicationName` returns the assembly name from the attribute. `WebAppBootstrap<TEntry>` passes it as `--applicationName`, so MVC finds the app's controllers.
- `Run` calls the app's entry point and returns its exit code. It returns 0 for an entry point that returns `void` or `Task`.
- `EntryPoint` is an `UnsafeAccessor` for the entry point. Its first parameter names the entry point's type as a string, such as `"Program, VoidApp"`, so the test project needs no access to that type. An internal `Program` and a static class work without `InternalsVisibleTo`.

The generator reads the entry point from the app's reference. In a build, a project reference passes the app's reference assembly. A reference assembly keeps only the method the compiler marks as the entry point. For an async entry point that is `<Main>`, which the compiler adds to call the method you wrote and wait for its task. The full assembly holds both methods, so an entry type for either one works when the test runs.

If the generator finds no entry point, or entry points in more than one type, it reports [VGA0001](../../diagnostics/VGA0001.md). A class that is not partial, is generic or is nested gets [VGA0002](../../diagnostics/VGA0002.md).

## The entry type for each shape

Each example below is the file the generator writes in a build, for an app with that entry point and a test project class in the namespace `Specs`. The specs in `test/VerificationGlue.Tests.AspNetCore.Generator.Specs` produce these files and call `Run` on each.

### Top-level statements that return nothing

The app's `Program.cs` ends with `app.Run();`. The compiler names the method `<Main>$`.

<!-- snippet: EntryTypeSpecs.Entry_type_for_VoidApp.verified.txt -->
<a id='snippet-EntryTypeSpecs.Entry_type_for_VoidApp.verified.txt'></a>
```txt
// <auto-generated/>
#nullable enable
namespace Specs;

partial class VoidAppEntry : global::VerificationGlue.Tests.AspNetCore.IWebAppEntry
{
    public static string ApplicationName => "VoidApp";

    public static int Run(string[] args)
    {
        EntryPoint(null, args);
        return 0;
    }

    [global::System.Runtime.CompilerServices.UnsafeAccessor(global::System.Runtime.CompilerServices.UnsafeAccessorKind.StaticMethod, Name = "<Main>$")]
    private static extern void EntryPoint(
        [global::System.Runtime.CompilerServices.UnsafeAccessorType("Program, VoidApp")] object? type,
        string[] args);
}
```
