# VGM0007: Return type is beyond the recursion depth

## What it means

An unconfigured member whose return type is an interface returns a mock of that interface, so `calc.History.Last.Returns(5)` works without setting up `History`. Those mocks are generated too, and the generator stops after a number of steps from each mocked type. `VerificationGlueMocksRecursionDepth` sets that number, and its default is 2.

A member of the last mock the walk reaches returns `null` when it is not set up, even though its return type is an interface. VGM0007 reports that member as information, at each place that names the mocked type the walk started from.

A type also named in `Mock.Of<T>()`, `[Mock]` or `[assembly: GenerateMock]` starts a walk of its own. Its members are then measured from it, and they report nothing until they are beyond the depth again.

Return types in `System` namespaces, such as `IServiceProvider` or `IEnumerable<T>`, never get a recursive mock and never report VGM0007.

## Example that triggers it

```csharp
public interface IShop { IOrders Orders { get; } }
public interface IOrders { IOrder Find(int id); }
public interface IOrder { ICustomer Customer { get; } }
public interface ICustomer { string Name { get; } }

var shop = Mock.Of<IShop>();
```

`IOrders` is one step from `IShop` and `IOrder` is two, so with the default depth `shop.Orders.Find(1).Customer` returns `null`. The build reports:

```text
info VGM0007: 'IOrder.Customer' returns 'ICustomer', which is beyond the recursion depth of 2, so an unconfigured call returns null. Raise VerificationGlueMocksRecursionDepth to return a mock.
```

## The fix

Set up the member when the test needs it, as in `shop.Orders.Find(1).Customer.Returns(Mock.Of<ICustomer>())`. That also makes `ICustomer` a mocked type of its own.

To raise the depth for the whole project, set the property in the project file:

```xml
<PropertyGroup>
  <VerificationGlueMocksRecursionDepth>3</VerificationGlueMocksRecursionDepth>
</PropertyGroup>
```

Each step can add many generated mocks for types with large interface graphs. The shape sweep in `docs/design/mocks-shape-sweep.md` measures how many. With the property set to 0, no member returns a recursive mock, and each member that could reports VGM0007.

## When to suppress it

Suppress it when the tests never reach the member, or when `null` is what they expect. It is information only and does not fail the build.
