# VG0008: A [Verify] method is not rewritten because its file declares a file type

## What it means

The method has `[Verify]` or an attribute marked `[VerifyRewrite]`, and its file declares a `file` type. Tier 3 writes the method's `__Verified` copy into another file, and a `file` type is visible only in its own file. The copied body could not use it, so the method is not rewritten and keeps tier 2 messages.

[`RewriteAnalyzerSpecs.cs`](../../test/VerificationGlue.Generator.Specs/RewriteAnalyzerSpecs.cs) holds the case that CI runs.

## Example that triggers it

```csharp
file sealed class Fixture
{
}

public partial class OrderTests
{
    [Verify]
    public static void VerifyTotal(Order order) => Verify(order.Total == 40);
}
```

The build reports:

```text
info VG0008: 'VerifyTotal' is not rewritten, because its file declares the file type 'Fixture', which a copy in another file cannot see. It gets tier 2 messages.
```

## The fix

Move the `file` type to another file, or make it `internal`:

```csharp
internal sealed class Fixture
{
}
```

## When to suppress it

Suppress it when the type must stay `file` and tier 2 messages are enough for the methods in that file.
