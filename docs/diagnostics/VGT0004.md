# VGT0004: A [VerifyTest] method cannot run

## What it means

The runner cannot call this `[VerifyTest]` method, so the generator does not register it and the test does not run. The message names the reason:

| Reason in the message | Cause |
|---|---|
| `is not public` | The method is `private`, `protected` or `internal`. |
| `is generic, and a test needs data rows to close it` | The method has type parameters. |
| `is in the generic type OrderTests` | The method's class, or a class around it, has type parameters. |
| `is in OrderTests, which generated code cannot reach` | The class, or a class around it, is `private`, `protected` or `file`. |
| `is not declared in a class or a struct` | The method is in an interface. |
| `is an instance method of an abstract class` | The runner cannot create an abstract class. Make the method static or move it to a class that is not abstract. |
| `is async void, so the runner cannot wait for it` | The runner would report the test as passed before it finishes. |
| `does not return void, Task or ValueTask` | The method returns a value that is not a task, or returns by reference. |
| `has a ref, out or in parameter` | The runner has no variable to pass. |
| `has the parameter values, whose type cannot be passed as an object` | The parameter is a pointer or a `ref struct` such as `Span<int>`, and the runner passes every argument as an object. |

## Example that triggers it

```csharp
public partial class OrderTests
{
    [VerifyTest]
    internal void M() { }
}
```

The build reports:

```text
warning VGT0004: The [VerifyTest] method 'M' is not public, so the runner does not register it
```

## The fix

Change the method so the reason no longer applies. For the example, make the method `public`. Turn an `async void` method into `async Task`.

## When to suppress it

Suppress it only for a method that should carry `[VerifyTest]` but not run, such as one kept for reference. Removing the attribute is clearer.
