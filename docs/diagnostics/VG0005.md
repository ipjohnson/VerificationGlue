# VG0005: A [Verify] method is in a type that is not partial

## What it means

The method has `[Verify]` or an attribute marked `[VerifyRewrite]`, but a type that contains it is not `partial`. Tier 3 writes the method's `__Verified` copy into the same type from a generated file, which needs every type in the chain to be `partial`. The method keeps tier 2 messages.

The code fix adds `partial` to each type in the chain. [`RewriteAnalyzerSpecs.cs`](../../test/VerificationGlue.Generator.Specs/RewriteAnalyzerSpecs.cs) and [`MakePartialCodeFixSpecs.cs`](../../test/VerificationGlue.Generator.Specs/MakePartialCodeFixSpecs.cs) hold the cases that CI runs.

## Example that triggers it

```csharp
public class OrderTests
{
    [Verify]
    public static void VerifyTotal(Order order) => Verify(order.Total == 40);
}
```

The build reports:

```text
info VG0005: 'VerifyTotal' cannot get a tier 3 copy because 'OrderTests' is not partial. Add 'partial' to each type that contains the method.
```

## The fix

Add `partial` to each type that contains the method:

```csharp
public partial class OrderTests
{
    [Verify]
    public static void VerifyTotal(Order order) => Verify(order.Total == 40);
}
```

## When to suppress it

Suppress it when the type must stay non-partial and tier 2 messages are enough for that method.
