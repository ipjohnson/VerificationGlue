# VG0004: Verify condition compares floating-point values exactly

## What it means

The condition of a `Verify` call compares `float` or `double` values with `==` or `!=`. Most decimal fractions have no exact binary form, so arithmetic that is right on paper can differ in the last bit. `0.1 + 0.2 == 0.3` is false.

The analyzer reports a comparison anywhere in the condition, outside lambdas.

[`VerifyAnalyzerSpecs.cs`](../../test/VerificationGlue.Generator.Specs/VerifyAnalyzerSpecs.cs) holds the cases that CI runs.

## Example that triggers it

```csharp
double total = 0.1 + 0.2;
Verify(total == 0.3);
```

The build reports:

```text
warning VG0004: 'total == 0.3' compares double values with '=='. Compare the difference with a tolerance instead.
```

## The fix

Compare the difference with a tolerance that suits the calculation:

```csharp
double total = 0.1 + 0.2;
Verify(Math.Abs(total - 0.3) < 0.000001);
```

## When to suppress it

Suppress it when the value must be exact, such as a value copied without arithmetic, or a comparison with `0` or a sentinel such as `double.MaxValue`.
