# VGA0002: [WebAppEntry] is on a class the generator cannot add to

## What it means

The generator writes the entry type as another part of the class marked `[WebAppEntry]`. It can do so only when the class is `partial`, is not generic and is not nested in another type. This class breaks one of these rules, so the generator wrote nothing for it.

## Example that triggers it

```csharp
[WebAppEntry("ShopApi")]
public sealed class ShopApiEntry;
```

The build reports:

```text
error VGA0002: The class 'ShopApiEntry' has [WebAppEntry], but it is not partial. The generator adds the entry type only to a partial class that is not generic and not nested.
```

A generic class reports "it is generic", and a class inside another type reports "it is nested in" with the name of that type.

## The fix

Declare the class `partial`, at the top level of a namespace, with no type parameters:

```csharp
[WebAppEntry("ShopApi")]
public sealed partial class ShopApiEntry;
```

The class needs no members. The generator writes them.

## When to suppress it

Do not suppress it. The class has no entry type, so `[WebApp<TEntry>]` that names it does not compile.
