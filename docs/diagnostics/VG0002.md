# VG0002: Verify condition is a constant

## What it means

The condition of a `Verify` call has the same value every time it runs, so the call checks nothing. `Verify(true)` always passes. `Verify(false)` always fails. A condition built only from constants, such as `Limit > 2` where `Limit` is a `const`, is a constant too.

[`VerifyAnalyzerSpecs.cs`](../../test/VerificationGlue.Generator.Specs/VerifyAnalyzerSpecs.cs) holds the cases that CI runs.

## Example that triggers it

```csharp
const int Limit = 3;
Verify(Limit > 2);
```

The build reports:

```text
warning VG0002: The condition 'Limit > 2' is always true, so this Verify call checks nothing
```

## The fix

Verify a value the code under test produces:

```csharp
var lines = order.Lines.Count;
Verify(lines > 2);
```

To fail a test on purpose, throw an exception that says why, such as `throw new InvalidOperationException("not reached")`.

## When to suppress it

Suppress it on a check that guards a constant you expect to change, such as a limit read from generated code that is a `const` today.
