# VGA0001: [WebAppEntry] names an assembly whose entry point the generator cannot find

## What it means

The generator could not find one entry point in the assembly that `[WebAppEntry]` names, so it wrote no entry type for the class. The message says which of these it found:

- The project does not reference an assembly with that name. The message lists the assemblies the project references, without the .NET and VerificationGlue assemblies.
- The assembly has no static method named `Main`, `<Main>` or `<Main>$` that returns `void`, `int`, `Task` or `Task<int>` and takes no parameters or a `string[]`. A class library has no entry point.
- More than one type in the assembly has an entry point. The message lists each one with its type and return type.

The name is the assembly name of the app, which is the project name unless the app's project sets `AssemblyName`.

## Example that triggers it

A test project that references `ShopApi.csproj`, whose `AssemblyName` is `ShopApi`, and names the project folder instead:

```csharp
[WebAppEntry("Shop.Api")]
public sealed partial class ShopApiEntry;
```

The build reports:

```text
error VGA0001: [WebAppEntry] names the assembly 'Shop.Api', but the project does not reference it. It references these assemblies outside .NET and VerificationGlue: ShopApi, ShopApi.Contracts
```

An app with a `Main` method in two classes reports:

```text
error VGA0001: [WebAppEntry] names the assembly 'ShopApi', but more than one type in it has an entry point: ShopApi.Program.Main(string[]) returning int, ShopApi.Tools.Migrate.Main(string[]) returning void
```

## The fix

Do the one that matches the message:

- Write the app's assembly name, as the message lists it, in `[WebAppEntry]`.
- Add a project reference from the test project to the app's project.
- Name the app's project, not a class library that the app uses.
- Keep one entry point in the app. The C# compiler needs the same with `StartupObject`, and the generator does not read that setting.

## When to suppress it

Do not suppress it. The class has no entry type, so `[WebApp<TEntry>]` that names it does not compile.
