# VGT0001: Two tests have the same ID

## What it means

Two `[VerifyTest]` methods have the same test ID. A test ID is the full name of the class, the method name and the parameter types, such as `Shop.OrderTests.Totals(System.Int32)`. MTP filters, retries and IDE history find a test by its ID, so each ID must name one test. The error is reported on each method that shares the ID.

C# does not allow two methods with the same signature in one class. Two IDs can still match when parameter types with the same full name come from different assemblies, through extern aliases.

## Example that triggers it

Two libraries each declare `Vendor.Item`, and the test project references them with the aliases `First` and `Second`:

```csharp
extern alias First;
extern alias Second;

public partial class OrderTests
{
    [VerifyTest]
    public void M(First::Vendor.Item item) { }

    [VerifyTest]
    public void M(Second::Vendor.Item item) { }
}
```

Both methods report:

```text
error VGT0001: The test ID 'OrderTests.M(Vendor.Item)' is also the ID of another test. Each test ID must be unique.
```

## The fix

Rename one of the methods, so the IDs differ.

## When to suppress it

Do not suppress it. When two tests share an ID, the runner refuses to start the session.
