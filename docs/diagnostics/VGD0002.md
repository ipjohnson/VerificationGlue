# VGD0002: A [ServiceCollection] attribute is on a narrower target than the scope that shares its container

## What it means

With `Scope = ContainerScope.Class` or `ContainerScope.Assembly`, `[ServiceCollection]` and `[ServiceCollection<T>]` build one container for the class or the assembly, before any test runs. A container of the class is built from the attributes of the class and the assembly. A container of the assembly is built from the attributes of the assembly alone. An attribute with `Scope = ContainerScope.Class` on a method, or with `Scope = ContainerScope.Assembly` on a class or a method, is not among those attributes. Its services would not reach the container, so the analyzer reports it as an error.

## Example that triggers it

```csharp
[ServiceCollection<ShopServices>(Scope = ContainerScope.Assembly)]
public partial class OrderHistoryTests
{
    [VerifyTest]
    public void Saves_an_order(OrderService sut, IOrderStore store)
    {
        // ...
    }
}
```

The build reports:

```text
error VGD0002: [ServiceCollection<Shop.Tests.ShopServices>] is on the class 'OrderHistoryTests' with Scope = Assembly, but a container shared with Scope = Assembly is built from the attributes of the assembly before any test runs, so it does not read this attribute. Move it to the assembly, or give it test scope.
```

The same holds for `Scope = ContainerScope.Class` on a test method. The message then asks to move the attribute to the class or the assembly.

## The fix

Put the attribute on the target its scope reads. For a container of the assembly, use `[assembly: ServiceCollection<ShopServices>(Scope = ContainerScope.Assembly)]`. For a container of the class, put the attribute on the class:

```csharp
[ServiceCollection<ShopServices>(Scope = ContainerScope.Class)]
public partial class OrderHistoryTests
```

If the tests do not need to share a container, remove `Scope`. Each test then builds its own container from the attributes of the assembly, the class and the method.

## When to suppress it

Do not suppress it. The shared container is built without the attribute's services, so the tests resolve services the attribute did not register.
