# VGT1001: dotnet test needs the Microsoft.Testing.Platform runner

## What it means

`dotnet test` on .NET 10 runs a project with VSTest unless the `global.json` next to the solution selects the Microsoft.Testing.Platform (MTP) runner. A `VerificationGlue.Tests` project is an MTP application, and VSTest cannot run it. The error comes from `build/VerificationGlue.Tests.targets`, which checks before the VSTest target runs.

The `dotnet` CLI reads `global.json` before it evaluates any project, so the package cannot set this. `dotnet build`, `dotnet run` and `dotnet publish` do not run the VSTest target, so they work without the setting.

## Example that triggers it

A `global.json` that pins the SDK and does not select a test runner:

```json
{
  "sdk": { "version": "10.0.403" }
}
```

`dotnet test` then fails with:

```text
error VGT1001: dotnet test needs the Microsoft.Testing.Platform runner for a VerificationGlue.Tests project. Add this to the global.json next to the solution: "test": { "runner": "Microsoft.Testing.Platform" }
```

## The fix

Add the runner to `global.json`:

```json
{
  "sdk": { "version": "10.0.403" },
  "test": { "runner": "Microsoft.Testing.Platform" }
}
```

Every test project in the solution then runs on MTP. xunit v3, MSTest, NUnit and TUnit support MTP too.

## When to suppress it

Do not suppress it. VSTest cannot run the tests. To run them without the setting, use `dotnet run` on the test project.
